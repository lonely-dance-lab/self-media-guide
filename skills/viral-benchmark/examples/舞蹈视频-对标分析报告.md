# 对标分析报告 · 舞房固定机位的单人爵士舞

> 这是用本 Skill 跑出来的示例。输入是 1 条下载到本地的小红书舞蹈视频，用户补了截图里的点赞、收藏和评论数。
> 原视频没有放进仓库，只保留分析过程。

## 一、视频概览

- 来源：小红书，本地文件
- 时长 / 画幅：28 秒，横屏
- 数据：点赞 5310 / 收藏 2855 / 评论 130；粉丝数、账号平时一条多少赞、发布日期待补

## 二、内容总结

一句话：一个女生在舞房里，固定机位、一镜到底，完整跳完一段爵士舞。

按时间线：

- 0–2 秒：人已经站在画面中央，双手举过头顶，直接起跳，没有铺垫
- 2–6 秒：侧步大跨，接连两次甩头，头发整个扬起来
- 6–10 秒：双臂前推、后仰，在 10 秒左右下沉，配合一次大幅度甩发，是全片动作最大的地方
- 10–18 秒：转身、开胯的宽站位，18 秒左右背对镜头双臂张开
- 18–28 秒：叉腰、甩发、手臂伸展，节奏稍缓，收在一个展开的动作上

全程从头到脚都在画面里，镜头没动过。

## 三、受众

- 谁在看：喜欢刷舞蹈视频的年轻观众，以及想学这支舞的人
- 为什么看：人好看、动作利落，阔腿裤和露腰上衣让每个动作都很显眼；歌好听
- 评论区在问什么：推测是在问舞名、歌名，或者某个动作怎么做（没有评论数据，需要你确认）

## 四、为什么能火

- 数据信号：收藏 2855，超过点赞的一半，说明很多人想留着学或者反复看。账号平时多少赞待补，补上才能判断是不是明显比平时好
- 开头 3 秒：第 0 秒人已经在跳，没有铺垫，留得住人
- 画面和节奏：固定机位、不切镜头，动作全靠卡点撑起来；2–6 秒的连续甩头和 10 秒左右的下沉甩发最抓眼
- 一句话：**好看的人 + 利落的卡点 + 一镜到底，观众的注意力全在动作上**

## 五、对标建议

- 结论：**值得对标**。形式简单、时长合适，换个人照样成立
- 换主角测试：过。固定机位、单人全身，换成别的人物，动作能不能跟上一眼就能对照；同一套拍法换一支舞还能接着做
- 借不走的：原舞者本人的舞技和长相。要用自己的人物替代，动作交给视频模型迁移
- 适合什么样的账号：舞蹈号、颜值号、有自己 IP 角色的账号

## 六、复刻思路

> 你想做的内容：同一支舞，换成自己的 IP 角色来跳（用户选的方向）

- 借什么：动作轨迹、固定机位、全身景别、卡点节奏
- 换什么：跳舞的人换成自己的 IP 角色，横屏改竖屏，造型和场景可以换

二创手法：

1. 换画幅：横屏改 9:16 竖屏，重点检查 2–6 秒甩头和 10 秒下沉时，头发和脚有没有出画
2. 换主角：换成自己的 IP 角色，补几张不同角度的脸部特写，防止甩头时变脸
3. 换造型和场景：同一支舞做几个不同风格的造型，或者换到街头
4. 加观点：把 10 秒左右那个下沉甩发单独截出来放慢，告诉大家难在哪

看过原片的人刷到这一条，还能看到：同一支舞换了一个人、换了风格，还能看清最难的那一下是怎么做的。

## 七、第一批三条选题

1. **同一支舞，甜妹、酷飒、慵懒三种风格，你选哪个？**：换主角 + 换造型，评论区天然有互动
2. **这支舞最难的，是第 10 秒这一下**：改节奏 + 加观点，把下沉甩发那两秒放慢
3. **这支舞换到街头再跳一遍**：换场景，测观众更喜欢舞房还是户外

发完看：

- 播放、完播：哪个方向更吸引人
- 收藏：第 2 条收藏高，说明大家想学，可以往拆动作的方向连做
- 评论：
  - 一直有人问是什么舞 → 下一条做完整版
  - 反复提某个动作 → 下一条找一支有类似卡点的舞再试

## 八、制作提醒

- 参考视频 + 角色首帧交给视频 Agent，比如 YouArt Desktop 的「爆款复刻」，说清楚要换什么就行
- 先用便宜的模型出样片（比如 Kling v3.0 Motion Control），看动作能不能跟上；确认没问题，再换效果更好的模型出成片（比如 Seedance 2.5）
- 这条甩头多，只给一张全身首帧很容易变脸，提前补 3–4 张不同角度的脸部特写
- 动作对不准的话，再试试把原视频转成白膜当动作参考
