# 规则与参考

## 筛选规则

### 去哪找（给用户补充对标时用）
- 同平台：小红书、抖音搜赛道关键词，按「最热」排序
- 跨平台：YouTube Shorts、TikTok、Instagram Reels 上已经火、国内还没铺开的形式
- 顺藤摸瓜：从一个爆款号出发，翻它的主页和评论区

### 判断是不是真爆款

| 信号 | 怎么看 | 说明 |
|---|---|---|
| 赞粉比 | 点赞 ÷ 粉丝 | ≥ 1 很强；0.3–1 不错；< 0.1 多半是靠粉丝基数，不是内容 |
| 形式被验证 | 同一种形式在几个号上火过 | 1 个号：可能是运气或人设；≥ 3 个号：形式被验证 |
| 新鲜度 | 发布日期 | 最近 1–2 个月还在火的优先 |
| 评论追问 | 评论区在问什么 | 追问越多，越说明观众还想看，也是选题来源 |

数据缺的时候不要猜，标「待补」，请用户补。

### 适合新手复刻
- 15–30 秒，结构一眼能看懂
- 不依赖真人的特殊技能、特殊场地或博主本人的人设
- 换成用户自己的素材，这条还成立
- 能连做三条以上

### 放弃或降级
- 头部大号的爆款：靠博主本人火，换了人就不灵
- 时效热点：做出来已经过气
- 影视剧片段、明星画面：版权敏感

### 结论
- **先做**：真爆款 + 适合新手 + 能连做
- **备选**：有一项待确认（比如只找到一个号火过）
- **放弃**：踩了红线，或换了素材就不成立

## 按类型拆

| 类型 | 靠什么火 | 借什么 | 换什么 |
|---|---|---|---|
| 舞蹈 / 变装 | 动作、卡点、画面冲击 | 动作、机位、景别、卡点节奏 | 人物、服装、场景 |
| 知识科普 / 口播 | 一个好问题 + 讲述顺序 | 开头的问题、信息展开顺序、结尾怎么收 | 知识点、讲述人、文案 |
| 剧情 / 段子 | 反转 | 铺垫 → 冲突 → 反转的节奏、台词长度 | 角色、情节、台词 |
| 萌宠 / 虚拟角色 | 拟人化 + 情绪 | 动作桥段、表情时机、配音语气 | 形象、台词 |
| 好物 / 开箱 | 前 3 秒钩子 + 使用对比 | 钩子句式、镜头顺序（痛点 → 使用 → 效果） | 产品、场景、卖点 |
| 资讯解说 | 选题时效 + 信息密度 | 标题句式、画面拼贴、旁白节奏 | 新闻、素材、观点 |

借不走的：原作者本人的经历、颜值、技能、独家素材。遇到这种，换一个用户自己有材料、能讲清楚的点。

动作类小技巧：先把原视频转成白膜（只保留动作的白色人体模型），再拿它当动作参考。原作者的身份信息去掉了，四肢动作也更容易对准。

## 二创手法

| 手法 | 怎么做 |
|---|---|
| 换画幅 | 横屏改竖屏，构图重排，检查主体有没有被裁掉 |
| 换主角 | 换成自己的 AI 角色、虚拟 IP、宠物或产品 |
| 换造型和场景 | 服装、发型、背景、光线 |
| 换声音 | BGM、自己的配音或旁白、换语种 |
| 改节奏 | 剪短，只留最炸的一段，重新调卡点 |
| 加包装 | 字幕、花字、标题条、封面 |
| 换题材 | 同一个结构套到自己的赛道，比如变装结构拿来讲穿搭 |
| 加观点 | 加自己的解说、点评、对比，二创里最「原创」的部分 |

每条对标至少叠 3 种，其中至少一种是「换题材」或「加观点」。

## 测反馈

- 先发三条：同一类观众，三个不同的切入点
- 播放、完播：题材有没有吸引力
- 收藏：内容有没有用
- 关注、评论：有没有人想继续看；评论区反复问的就是下一条选题
- 想测开头：同一条内容只换开场
- 没起来就换对标，不要在一条上死磕

## 变现对照

| 方式 | 看什么 |
|---|---|
| 接商单 | 能不能稳定吸引同一类人；做过的片子就是案例 |
| 自己的产品或服务 | 点击、私信、咨询 |
| 带货分佣 | 商品点击和成交 |
| 二创接单 | 有人带着素材和参考视频来找你：先给样片，问清借开头还是整条节奏，看素材够不够，再按交付物、时间、修改轮数报价 |
