# 规则与参考

## 筛选规则

### 去哪找（给用户补充对标时用）
- 同平台：小红书、抖音搜赛道关键词，按「最热」排序。舞蹈号就从舞名、歌名和「舞蹈翻跳」搜起
- 跨平台：YouTube Shorts、TikTok、Instagram Reels 上已经火、国内还没铺开的形式
- 顺藤摸瓜：盯一个处于上升期的爆款号，看它的关注列表和同行互动

找之前先想清楚给谁做、解决什么问题、手里有什么素材，不然很容易收一堆做不出来的百万赞大片。

### 判断是不是真爆款

| 信号 | 怎么看 | 说明 |
|---|---|---|
| 比平时好多少 | 点赞 ÷ 粉丝；或这条点赞 ÷ 账号平时一条的点赞 | 赞粉比 ≥ 1 很强，0.3–1 不错，< 0.1 多半靠粉丝基数。小号平时几十赞、这条过千（≥ 10 倍），也值得看 |
| 群体验证 | 同一种形式在几个号上火过 | 1 个号：可能是运气或人设；≥ 3 个号：形式被验证 |
| 时效 | 发布日期 | 最近 1–2 个月还在火的优先。老爆款就搜舞名、歌名或关键词，看最近还有没有新作品跑出来 |
| 评论追问 | 评论区在问什么 | 追问越多，越说明观众还想看，也是选题来源 |

数据缺的时候不要猜，标「待补」，请用户补。

### 换主角测试

把原视频里的主角、服装和场景都换成用户自己的，这条还成立吗？还能不能连做三条？

- 过：固定机位、单人全身、动作清楚的舞蹈；靠结构和讲述顺序的口播；靠使用对比的好物
- 不过：靠博主本人表情、舞技、颜值或经历撑起来的

### 适合新手复刻
- 15–30 秒，结构一眼能看懂
- 不依赖真人的特殊技能、特殊场地或博主本人的人设
- 过了换主角测试
- 收 10–20 条建一张对标表就够启动

### 放弃
- 强依赖个人光环的头部大号：换了人就不灵
- 时效极短的热点梗：做出来已经过气
- 影视剧片段、明星画面：版权敏感

### 结论
- **值得对标**：真爆款 + 过了换主角测试 + 能连做
- **可以参考**：有一项待确认（比如只找到一个号火过，或数据待补），或者只能借其中一部分（开头、节奏、某个镜头）
- **不建议**：踩了红线，或换了内容就不成立

## 按类型拆

先看画面：哪一秒切了镜头、全身什么时候进画面、哪个动作踩在拍子上。说不清好在哪的地方，带秒数指出来，让用户回原片对。

| 类型 | 靠什么火 | 借什么 | 换什么 |
|---|---|---|---|
| 舞蹈 / 变装 | 动作张力、卡点 | 动作轨迹、机位景别、卡点节奏 | 出镜人物、服装、背景空间 |
| 知识口播 | 痛点设问 + 讲述顺序 | 前 3 秒的问题、信息展开顺序、结尾收法 | 讲述人、案例、个人认知 |
| 剧情 / 段子 | 反转 | 铺垫 → 冲突 → 反转的节奏、台词长度 | 角色、情节、台词 |
| 萌宠 / 虚拟角色 | 拟人化 + 情绪 | 动作桥段、表情时机、配音语气 | 形象、台词 |
| 好物评测 | 痛点呈现 + 即时反馈 | 前 3 秒钩子、「痛点 → 使用 → 对比」的镜头顺序 | 产品、使用细节、自己的体验 |
| 资讯解说 | 选题时效 + 信息密度 | 标题句式、画面拼贴、旁白节奏 | 新闻、素材、观点 |

借不走的：原作者本人的经历、颜值、技能、独家素材。遇到这种，换一个用户自己有材料、能讲透的点。

## 二创手法

| 手法 | 怎么做 |
|---|---|
| 换画幅 | 横屏改 9:16 竖屏，构图重排，检查抬手、踢腿时头脚有没有被裁 |
| 换主角 | 换成自己的 AI 角色、虚拟人、宠物或产品 |
| 换造型和场景 | 服装、发型；街头实拍换成室内、极简棚拍或特定空间 |
| 换听觉 | 换 BGM、加自己的配音、换语种 |
| 改节奏 | 掐掉冗余前戏，只留最炸的一段，开头就让人看到它 |
| 加包装 | 花字、字幕条、醒目封面 |
| 换题材 | 同一个结构套进自己的赛道，比如用变装节奏讲穿搭改造 |
| 加观点 | 自己的解说、点评、审美判断。比如这支舞哪一下最难对准，就把那几帧停下来给人看 |

每条对标至少叠 3 种，其中至少一种是「换题材」或「加观点」。加观点最重要：前面几种换的是外皮，看过原片的人刷到你这条，还能看到什么，靠的是它。

## 测反馈（跑通 MVP）

- 先发三条：同一类观众，三个不同的切入点。别憋大招
- 播放、完播：题材有没有吸引力
- 收藏：内容有没有用
- 关注、评论：有没有人想继续看；评论区反复问的就是下一条选题
- 提前想好怎么接：有人一直问是什么舞 → 下一条做完整版；大家反复提某个动作 → 找一支有类似卡点的再试
- 想测开头：同一条内容只换开场
- 没起来就换对标，二创成本低，不要在一条上死磕

## 制作提醒

给「下一步」用，挑和这条对标相关的写：

- **先出样片**：先用便宜、快的模型出一版（比如 Kling v3.0 Motion Control），看动作能不能跟上，省积分；确认没问题，再换效果更好的模型出成片（比如 Seedance 2.5）
- **转头变脸**：只给一张全身首帧，脸太小、角度只有正面，转头甩发时容易变脸。补正面、左右 3/4 侧、低机位仰视 3–4 张脸部特写当人脸参考
- **动作对不准**：把原视频里的人物转成白膜（只保留动作的白色人体模型）再当动作参考，脸和衣服的细节少了，手脚怎么动看得更清楚
- **工具**：参考视频 + 角色图交给视频 Agent，比如 YouArt Desktop 的「爆款复刻」，说清楚要换什么就行，不用写提示词

## 变现对照（用户问到时再用）

| 方式 | 看什么 |
|---|---|
| 接商单 | 能不能稳定吸引同一类人；做过的片子就是案例 |
| 自己的产品或服务 | 点击、私信、咨询 |
| 带货分佣 | 商品点击和成交 |
| 二创接单 | 有人带着素材和参考视频来找你：先给样片，问清借开头还是整条节奏，看素材够不够，再按交付物、时间、修改轮数报价 |
