# （一）如何快速起号

先借已经被验证过的爆款骨架，换成自己的血肉，小步测试，再决定往哪个方向变现。

核心是二创，不是搬运。

## 方法论一页纸

### 1. 找对标

- **先定你要吸引谁**：我给谁做、他遇到什么问题、我手里有什么素材或经验
- **去哪找**
  - 同平台：小红书、抖音搜赛道关键词，按「最热」排序
  - 跨平台：YouTube Shorts、TikTok、Instagram Reels 上已经火、国内还没铺开的形式
  - 顺藤摸瓜：从一个爆款号出发，看它关注了谁、评论区在提谁
- **怎么判断是真爆款**
  - 相对数据：点赞远高于粉丝数（1 万粉出了 10 万赞）
  - 同一种形式在好几个号上都火过
  - 最近一两个月还在火
  - 评论区在追问
- **适合新手**：15–30 秒、结构一眼能看懂、不依赖真人特殊技能、换主角还成立
- **别碰**：头部大号的爆款、时效热点、影视剧和明星画面

### 2. 拆骨架

先判断它靠什么火，再决定拆什么。详见 [`拆解笔记模板.md`](拆解笔记模板.md)。

动作类视频的小技巧：先把原视频转成白膜（只保留动作的白色人体模型），再拿它当动作参考。原作者的身份信息去掉了，四肢动作也对得更准。

### 3. 换血肉

能叠几种二创手法就叠几种。详见 [`二创清单.md`](二创清单.md)。

### 4. 先发三条

- 围绕同一类人、同一个问题做三条，只换开头
- 播放、完播看题材吸引力；关注、评论看有没有人想继续看
- 评论区反复被问的问题，就是下一条选题
- 一条没起来就换对标

### 5. 怎么赚钱

- **接商单**：能不能反复吸引同一类人，选题和可能合作的产品是否相关
- **自己的产品或服务**：看点击、私信、咨询
- **带货分佣**：看点击和成交，选题阶段就想清楚观众为什么需要这个东西

## 实操示例

我用一条舞蹈视频走了一遍：横屏原片 → 竖屏 AI 角色版，28 秒。过程写在配套文章里。
