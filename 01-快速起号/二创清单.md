# 二创清单

能叠几个就叠几个。叠得越多，越是你自己的东西。

- [ ] **换画幅**：横屏原片做成竖屏，适配小红书和抖音。构图跟着重排，不是简单裁切
- [ ] **换主角**：真人换成自己的 AI 角色、虚拟 IP、宠物或产品
- [ ] **换造型和场景**：服装、发型、背景、光线
- [ ] **换声音**：换 BGM，加自己的配音或旁白，或者换语种
- [ ] **改节奏**：剪短，只留最炸的一段，或者重新调卡点
- [ ] **加包装**：字幕、花字、标题条、封面
- [ ] **换题材**：同一个结构套到自己的赛道，比如变装结构拿来讲穿搭知识
- [ ] **加观点**：加自己的解说、点评、对比，这是二创里最「原创」的部分
