# 拆解笔记模板

## 一行笔记

每拆一条对标，记一行：

```
参考视频 | 给谁看 | 开头承诺了什么 | 中间怎么证明 | 我能加什么
```

示例：

```
@某舞蹈号 28 秒舞蹈 | 喜欢刷舞蹈视频的年轻观众 | 前 2 秒就进入卡点动作 | 固定机位一镜到底，靠动作和卡点撑满 | 换成自己的 IP 角色，横屏改竖屏，最难的卡点放慢
```

拆的时候可以直接把原片丢给视频 Agent，让它给出分镜、节奏和切点，你判断它拆得对不对。

## 先判断它靠什么火

### 舞蹈 / 变装
- 靠什么火：动作、卡点、画面冲击
- 借：动作、机位、景别、卡点节奏
- 换：人物、服装、场景

### 知识科普 / 口播
- 靠什么火：一个好问题 + 讲述顺序
- 借：开头抛的问题、信息展开顺序、结尾怎么收
- 换：知识点、讲述人、文案

### 剧情 / 段子
- 靠什么火：反转
- 借：铺垫 → 冲突 → 反转的节奏、台词长度
- 换：角色、情节、台词

### 萌宠 / 虚拟角色
- 靠什么火：拟人化 + 情绪
- 借：动作桥段、表情时机、配音语气
- 换：形象、台词

### 好物 / 开箱
- 靠什么火：前 3 秒钩子 + 使用对比
- 借：钩子句式、镜头顺序（痛点 → 使用 → 效果）
- 换：产品、场景、卖点

### 资讯解说
- 靠什么火：选题时效 + 信息密度
- 借：标题句式、画面拼贴方式、旁白节奏
- 换：具体新闻、素材、观点
